発車メロディ早押しクイズ・オフライン版

このフォルダー内のファイル一式を、同じ場所に置いたままHTTPS対応の静的サイトとして公開してください。
index.html だけを単独でアップロードしても、オフライン保存機能は動きません。

初回準備（インターネット接続が必要）
1. 公開したHTTPSのURLをiPadのSafariで開きます。
2. 画面上部に「オフライン利用の準備ができています」と表示されるまで待ちます。
   初回に「Safariでこのページを一度再読み込みしてください」と出た場合は、再読み込みしてください。
3. Safariの共有ボタンから「ホーム画面に追加」を選び、追加します。
4. ホーム画面にできたアイコンからアプリを一度起動し、画面が表示されることを確認します。
5. Wi-Fiなどを切断し、ホーム画面のアイコンから再度起動できることを確認します。

普段の使い方（オフライン）
- ホーム画面のアイコンから起動します。
- iPadの「ファイル」アプリに保存してあるMP3を、アプリ画面のファイル選択から選びます。
- アプリを閉じた後、MP3の選択状態は保持されないことがあります。再起動後はMP3を選び直してください。

注意
- HTMLを「ファイル」アプリから直接開く方法では、Service Workerを登録できません。
- 初回準備後はアプリ本体の読み込みにネット接続は不要です。
- MP3はアプリに同梱・アップロードしません。選んだ音源は端末内で読み込みます。
- この版はオフライン動作を意図した構成ですが、実際のiPadで機内モード等による確認を行ってください。
